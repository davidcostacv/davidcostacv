- 🤖 **Approach:** plain scripts when the rules are predictable (fast, zero AI cost), AI only where the input is messy
- 🎧 **Also:** DJ, so some of my tools are for music

`Python` · `Browser automation`

### CreditParse / FORM 605 suite *(private)*
AI extraction tools that read credit report screenshots and output inquiries, addresses and tradelines as dispute-ready text, using the Anthropic vision API.
`Python` · `JavaScript` · `Claude API`

### [Market-bot](https://github.com/davidcostacv/Market-bot)
A collection of bots and automations:
- **Market Pulse:** a scheduled scan that turns market news into a scored, deduplicated feed with a live dashboard, and only notifies when something really matters.
- **Stock alerts (n8n):** Telegram alerts filtered by AI, plus on-demand reports in Spanish.
- **WhatsApp Macro Bot:** text it what you ate and it replies with the macros and your running total for the day.

`Python` · `Node.js` · `n8n` · `Telegram` · `WhatsApp`

`Python` · `SQLite` · `Spotify API` · `GetSongBPM`
